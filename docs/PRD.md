# מסמך אפיון מוצר - PRD (Product Requirements Document)
## פלטפורמת TutorDirect - Marketplace למורים פרטיים וייעוץ לימודים מבוסס AI

---

## 1. תקציר מנהלים וצורך עסקי (Executive Summary)
פלטפורמת **TutorDirect** היא פלטפורמת Marketplace מודרנית ואינטואיטיבית שנועדה לחבר באופן ישיר, מהיר ושקוף בין מורים פרטיים לבין תלמידים וסטודנטים. הפלטפורמה פותרת את חוסר היעילות, פערי התיווך והקושי באיתור מורה פרטי מדויק ומותאם אישית.

### הבעיות העיקריות בשוק המסורתי:
1. **חיפוש מבוזר ולא יעיל:** תלמידים מחפשים מורים בקבוצות פייסבוק, לוחות מודעות ואתרי אינדקס ישנים ללא מנגנון סינון מתקדם, ללא שקיפות מחירים וללא זמינות מעודכנת.
2. **חוסר התאמה פדגוגי:** תלמידים מתקשים להגדיר מה בדיוק הקושי הלימודי שלהם ואיזה מורה יתאים להם (רמת לימוד, סגנון הוראה, רקע אקדמי).
3. **סרבול בתיאום שיעורים:** עשרות הודעות טלפון ו-WhatsApp עד למציאת מועד פנוי הדדי.
4. **חוסר אמון ובקרה:** היעדר ביקורות מאומתות ודירוגים אמיתיים של תלמידים.

### הפתרון של TutorDirect:
* **איתור וסינון מדויק בזמן אמת:** סינון רב-שכבתי לפי מקצוע, מחיר מקסימלי, דירוג, רמת לימוד ומילות מפתח.
* **יועץ לימודים חכם מבוסס בינה מלאכותית ("איידן"):** מבוסס מודל **Gemini 3.5 Flash** המנתח את צרכי התלמיד אל מול פרופילי המורים הקיימים במערכת וממליץ על המורים המתאימים ביותר.
* **תיאום שיעור עצמאי בלחיצת כפתור (Self-Service Booking):** המורים מנהלים יומן זמינות (Time Slots), והתלמיד בוחר מועד פנוי ישירות מתוך הפרופיל.
* **תקשורת ישירה (Direct Chat):** מערכת הודעות מובנית לתיאום ציפיות, שאלות מקדימות והעברת חומרי לימוד.
* **שקיפות ואיכות:** מערכת חוות דעת ודירוגים בלעדית לתלמידים.

## 2. קהלי היעד ופרופילי משתמשים (User Personas)

המערכת מגדירה שני קהלי יעד עיקריים בעלי הרשאות, צרכים ומסכי פעולה מובחנים (Role-Based Architecture):

```
                     ┌───────────────────────────┐
                     │    משתמשי TutorDirect     │
                     └─────────────┬─────────────┘
                                   │
                 ┌─────────────────┴─────────────────┐
                 │                                   │
        ┌────────▼────────┐                 ┌────────▼────────┐
        │  תלמיד/סטודנט   │                 │   מורה פרטי     │
        │    (Student)    │                 │    (Teacher)    │
        └─────────────────┘                 └─────────────────┘
```

### א. פרופיל התלמיד (Student)
* **מאפיינים:** תלמידי יסודי, חטיבה, תיכון או סטודנטים במוסדות להשכלה גבוהה הזקוקים לתגבור לימודי או הכנה למבחנים.
* **מטרות עיקריות:**
  * מציאת מורה איכותי בטווח התקציב האישי.
  * בחירת מועד שיעור שמשתלב בלוח הזמנים.
  * קבלת המלצות מותאמות אישית דרך יועץ ה-AI.
  * מעקב אחר היסטוריית השיעורים שהוזמנו.
* **הרשאות ויכולות במערכת:**
  * חיפוש, סינון ומיון מורים.
  * תיאום שיעורים מחלונות זמן פנויים.
  * כתיבת חוות דעת ודירוג מורים.
  * פנייה ליועץ ה-AI ("איידן") והתייעצות חופשית.
  * ניהול צ'אט עם מורים וצפייה בשיעורים שהוזמנו.

### ב. פרופיל המורה הפרטי (Teacher)
* **מאפיינים:** סטודנטים מצטיינים, מורים מקצועיים או אקדמאים המעוניינים להציע שירותי הוראה פרטית.
* **מטרות עיקריות:**
  * חשיפה לקהל תלמידים רחב וממוקד ללא עמלות תיווך מופקעות.
  * ניהול עצמאי ופשוט של יומן הזמינות ומחיר השיעור.
  * ניהול הבקשות והשיעורים הנכנסים במקום אחד.
* **הרשאות ויכולות במערכת:**
  * פתיחה ועדכון פרופיל מורה מורחב (השכלה, ניסיון, תחומי לימוד, ביוגרפיה, טלפון, מחיר).
  * הוספה, עריכה ומחיקה של חלונות זמן פנויים (Time Slots).
  * צפייה בשיעורים שהוזמנו על ידי תלמידים ואישור/ביטול שיעור.
  * מענה בצ'אט לתלמידים מתעניינים.
  * *הערת הרשאה:* מורים אינם רשאים לדרג מורים אחרים או לתאם שיעור אצל מורים אחרים.

## 5. פירוט הפיצ'רים המרכזיים במערכת (Core Features)

### 1. מנוע חיפוש, סינון ומיון מתקדם (Search & Filter Engine)
* חיפוש טקסט חופשי לפי שם מורה, מקצוע, או מילות מפתח בביוגרפיה.
* סינון לפי מקצוע (מתמטיקה, אנגלית, מדעי המחשב, פיזיקה, כימיה, לשון ועוד).
* סינון לפי רמת לימוד (יסודי, חטיבה, תיכון, 3/4/5 יח"ל, אקדמיה).
* סליידר מחיר מקסימלי עם טווח גמיש (עד 400 ₪).
* מיון לפי דירוג (גבוה לנמוך), מחיר (עולה / יורד), וכמות ביקורות.

### 2. יועץ לימודים חכם מבוסס AI ("איידן" - Aiden)
* מודל שיחה אינטראקטיבי המבוסס על **Gemini 3.5 Flash**.
* הזרקת נתוני המורים הפעילים בזמן אמת ל-System Prompt, כך שה-AI ממליץ אך ורק על מורים אמיתיים הרשומים במערכת.
* שמירת היסטוריית שיחה ב-LocalStorage לשימור רצף השיחה.
* כפתור "שיחה חדשה" עם מודל אישור ייעודי למניעת מחיקות בטעות.

### 3. כרטיס ופרופיל מורה מפורט (Tutor Profile & Drawer)
* תצוגת ביוגרפיה, השכלה, שנות ניסיון, תחומי הוראה ומחיר לשעה.
* רשימת חלונות זמן פנויים ותפוסים.
* צפייה בחוות דעת של תלמידים והוספת חוות דעת חדשה עם דירוג כוכבים ואפשרות לפרסום אנונימי.

### 4. מערכת צ'אט פנימית (Messaging System)
* שיחה ישירה בין תלמיד למורה.
* תצוגת היסטוריית הודעות, מונה הודעות שלא נקראו וסנכרון מיידי.

### 5. אימות משתמשים וניהול פרופיל (Auth & User Profile)
* הרשמה והתחברות נוחה עם בחירת תפקיד (תלמיד או מורה).
* מודל פרופיל אישי לעדכון שם, טלפון ותמונת פרופיל (אוואטר).
* מנגנון איפוס סיסמה מאובטח באמצעות קוד חד-פעמי (OTP) הנשלח במייל דרך API ייעודי.
